Access Levels

✏️

Write Access

User can add expenses, delete expenses, update trip settings and modify custom splits.

👁️

Read Only

User can view expenses, totals, settlements and trip information, but cannot modify data.

🔐

Administrator

Administrator can manage member accounts, passwords and permissions.

Important

Member passwords are stored as secure password hashes. The administrator cannot view an existing password. Setting a new password replaces the old one.

New accounts initially use change-me. Set a proper password from this dashboard before giving the credentials to the member.
